API para empresas

Para e-commerces, bancos, transportadoras e outros sistemas — verificar endereços e criar entregas automaticamente. Todos os pedidos levam o cabeçalho x-api-key.

POST /v1/address/verify — { postal_code | plus_code | latitude+longitude }
POST /v1/address/reverse — { latitude, longitude }
POST /v1/address/search — { street_name?, place_kind?, limit? } → vários resultados
POST /v1/address/normalize — { free_text, country_code? } → morada normalizada
POST /v1/territory/lookup — { latitude, longitude | postal_code } → província/município/comuna/bairro/quadra/rua
GET /v1/address/{codigo_postal}
POST /v1/delivery/create — { postal_code | address_id, recipient_name, recipient_phone?, instructions? }
GET /v1/delivery/{tracking_code}
POST /v1/location/share — { latitude, longitude, label?, expires_at? } → localização oficial partilhável
🌐 Plataforma de localização como serviço
A API deixa de ser apenas uma interface da app e passa a funcionar como camada B2B/B2G de identidade territorial. Cada integração deve receber apenas os dados autorizados ao seu caso de uso.
🏦 Banco
validar e normalizar morada antes de KYC/cadastro.
🛒 E-commerce
validar destino, criar entrega e obter tracking.
🚚 Transportadora
validar destino, consultar território e operar última milha.
🏛️ Governo
consultar território e dados geográficos conforme permissões.
🏢 Empresa
normalizar moradas e resolver coordenadas/território.
📍 Pessoa
partilhar uma localização oficial com validade e controlo de acesso.
